## 폴더구조
```
•
├── app : 전역컴포넌트 (전역설정, Provider, Router, Client - slice)
│   └──  
├── pages : router 페이지(주소별 페이지, 각각의 주소별 페이지 slice)
├── feature : 동작하는 이벤트, 액션(행동, 동사가 slice, api segment에서는 해당행동 요청함)
├── entities : 컴포넌트, 데이터조회 (데이터, 데이터가 slice,  api segment 데이터 조회)
├── widgets : layouts (feature의 묶음)
└── shared :hooks, typings, utils (공유컴포넌트, slice없음 세그먼트만 존재)

```
